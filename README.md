## RTK Flag Values

The `RtkFlag` value represents the positioning status:

- **0** - Failed to determine position
- **16** - Single point positioning (meter-level accuracy)
- **32-49** - Floating point solution positioning (decimeter- to meter-level accuracy)
- **50** - Fixed solution positioning (centimeter-level accuracy)
